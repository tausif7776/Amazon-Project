# 🛒 Amazon Clone Project

Amazon Clone is a frontend web project inspired by the Amazon website.  
This project is created for learning and practicing web development skills using HTML, CSS, and JavaScript.

---

## 📌 Project Description

This project replicates the basic look and feel of Amazon’s eCommerce platform.  
It includes product listings, a shopping cart system, and a responsive UI.  
The main goal of this project is to improve frontend development and JavaScript logic.

---

## ✨ Features

- Amazon-style homepage layout  
- Product cards with image, title, and price  
- Add to Cart functionality  
- Cart page with selected products  
- Responsive design for mobile and desktop  
- Clean and simple UI  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript  
- Font Awesome  
- Google Fonts
